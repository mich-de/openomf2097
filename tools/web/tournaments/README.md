# Fan-made tournaments

Tournaments made by One Must Fall 2097's players between 1995 and 2002, as collected on X-BoT's OMF Universe
(omf.niraj.ws, read through the Internet Archive: <https://web.archive.org/web/20180809041902/http://omf.niraj.ws/2097tourn.htm>).
The web build puts them in its resources next to the original four, and the tournament mode lists them all.

Only the files the game reads are here: the `.TRN` and its `.PIC`. `trnfix.c` re-saved each `.TRN` so that its photos
are in its own `.PIC`, named after it (several used `WORLD.PIC`, two were both `MASTER.TRN`, one was `WORLD.TRN`),
and so that the two whose own `.BK` is not in their download use `WORLD.BK`. Nothing else is changed. Seven of the
page's tournaments are not in the archive, and the "heavy" downloads are the same tournaments as the "light" ones.
Some have pilots whose photo is not in their `.PIC`: those get its first photo (`tools/web/tournament-pilots.patch`, `chr.c`).
