# Hacked robots

Two robots One Must Fall 2097's players made by editing the original robots' `.AF` files, as
collected on X-BoT's OMF Universe (omf.niraj.ws, read through the Internet Archive:
<https://web.archive.org/web/20180809041902/http://omf.niraj.ws/2097downloads.htm>). The web build
adds them as robots of their own, on the robot grid's second page; the files are as their authors
made them, renamed for the build's resources.

## SUPERJAG: `FIGHTR12.AF`

"Навороченный Ягуар 2.0" (the souped-up Jaguar), © Илья (Ilya), 2000 (`hacked_jag.zip`, `jag2.af`).
Jaguar with new secret moves; * wants an enhancement, which every robot has outside the tournament:

| Move | Keys |
|---|---|
| Earthquake | Down, Down + Punch |
| Spinner | Forward, Forward + Kick |
| Press | Down + Punch, in the air |
| * Exploding spit | Down, Down-Back, Back + Punch, or Down, Down + Punch |
| Invisible breakthrough | Down, Down-Forward, Forward + Punch |
| Visible breakthrough | Down, Down-Forward, Up, Forward + Punch |
| Breakthrough (Thorn's) | Forward, Forward + Punch |
| Air-to-ground rocket (Nova's) | Down, Forward + Punch, in the air |
| Teleport (Chronos's) | Down, Down + Kick |
| Suicide | Up, Up + Punch, after a lost fight |

## SHADOW X: `FIGHTR13.AF`

A hacked Shadow, author unknown (`hacked_shadow.zip`, `FIGHTR1.AF`, 1998). Some moves made simpler:

| Move | Keys |
|---|---|
| Double shadow dive | Down, Down + Punch |
| Freeze / shadow grab | Down, Down-Forward, Forward + Punch |
| Shadow kick | Down, Down-Back, Back + Kick, jumping |
| Shadow slide | Down, Down-Back, Back + Punch |
| Scrap | Kick |
| Destruction | Tap Down, Punch quickly |
